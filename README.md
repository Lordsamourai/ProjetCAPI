# ProjetCAPI

## Installation

Cloner le projet :

```bash
git clone https://github.com/Lordsamourai/ProjetCAPI.git
```

Accéder au dossier contenant l'application :

```bash
cd src
```

Installer les dépendances :

```bash
npm install
```

## Lancer l'application

Depuis le dossier `src` : 

```bash
npm run dev
```

## Lancer les tests

Depuis le dossier `src` :

```bash
npm run test
```
